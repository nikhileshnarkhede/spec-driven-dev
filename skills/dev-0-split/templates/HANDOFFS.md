# Handoffs between sub-specs

Obligations one sub-spec leaves for a later one: an accepted limitation, a call the later unit must make, a value it must pass on. Fix-review and `/dev-auto` add rows; `/dev-1-select` copies open rows addressed to a unit into its contract; `/dev-6-final` closes them.

Status is `open`, `done (NN, how)` or `dropped (reason, user YYYY-MM-DD)`.
